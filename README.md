# FS_Chat / Намери Секс - Децентрализиран Чат

Напълно децентрализирано приложение за лични разговори, запознанства и анонимен глас без размяна на реални IP адреси, базирано на глобалния криптографски протокол **NOSTR** (NIP-01, NIP-04, NIP-17, NIP-28).

---

## 🌟 Как работи хостването и пускането чрез GitHub?

Ако експортирате този проект в **GitHub** (чрез бутона `Export > Push to GitHub`), получавате пълен контрол над приложението:

### 1. Безплатно онлайн хостване с 1 клик (за компютри и телефони):
Тъй като чатът е децентрализиран и използва NOSTR релета (не изисква централизирана база данни), можете да го пуснете безплатно онлайн:
- **Vercel** ([vercel.com](https://vercel.com)): Свързвате вашия GitHub акаунт, избирате хранилището и натискате **Deploy**. След 30 секунди получавате собствен постоянен публичен адрес (напр. `https://fs-chat.vercel.app`).
- **Netlify** ([netlify.com](https://netlify.com)) или **Cloudflare Pages**: Също напълно безплатни с автоматично обновяване при всеки git push.
- **Този публичен адрес може да се отваря от всеки човек по света, от всяко устройство без Google AI Studio ограничения!**

---

### 2. Сваляне на изпълними файлове (Windows .exe и Android .apk) чрез GitHub Releases:
Във вашето GitHub хранилище има секция **Releases** (вдясно на екрана):
1. Отидете на **Releases** -> **Draft a new release**.
2. Поставете етикет (Tag), например `v1.0.0`.
3. Прикачете файловете за сваляне:
   - `FS_Chat.exe` (самостоятелен файл за Windows)
   - `FS_Chat-Windows.zip` (архив с програмата и упътвания)
   - `FS_Chat.apk` (инсталационен пакет за Android)
4. Натиснете **Publish release**.
5. GitHub генерира постоянни директни линкове за сваляне на пълна скорост, без пароли и ограничения!

---

### 3. Как да направите Android инсталационен пакет (.APK)?
1. След като хоствате сайта си (напр. във Vercel: `https://вашето-приложение.vercel.app`).
2. Отворете безплатния официален инструмент на Microsoft: **[PWABuilder.com](https://www.pwabuilder.com)**.
3. Въведете адреса на вашия сайт и натиснете **Start**.
4. Натиснете **Package for Android** -> **Generate APK / Signed Package**.
5. Изтегляте готовия **`.apk`** файл и го качвате в GitHub Releases. Потребителите на Android го свалят и инсталират директно на телефона с 1 клик!

---

### 4. Стартиране локално на компютър (Local Dev / Offline):
```bash
# 1. Инсталиране на зависимостите
npm install

# 2. Стартиране за разработка
npm run dev

# 3. Сглобяване за продукция
npm run build
npm start
```
Отворете в браузъра: `http://localhost:3000`

---

## 🔒 Сигурност и поверителност:
- **Криптиране от край-до-край (NIP-17 Gift Wrap):** Никой (дори релетата) не вижда съдържанието, изпращача или получателя.
- **Анонимен глас през релета (Ephemeral Kind 20000+):** Без директни WebRTC P2P връзки – вашият реален IP адрес остава напълно скрит.
- **Локална база (IndexedDB):** Всички съобщения и ключове се пазят единствено на вашето устройство.
